## 💡 Как это работает

При интенсивном вайбкодинге бесплатные модели быстро упираются в рейт-лимиты (**ошибка 429**), а сторонние клиенты блокируются сервером (**ошибка 403 FreeTierError**). 

Данный прокси решает обе проблемы:
1. **Обход 403 FreeTierError**: автоматически генерирует каноничные сессионные сигнатуры (`tU`-алгоритм OpenCode), подставляет официальный `User-Agent` и полный набор системных инструментов (`tools`). Сервер принимает запросы как от официального клиента.
2. **Бесконечный вайбкод (Auto-Rotation & Cooldown)**: распределяет нагрузку между вашими аккаунтами. Если один аккаунт исчерпал лимиты (429), прокси временно отправляет его отдыхать на 60 секунд и **мгновенно и незаметно** повторяет запрос через следующий живой аккаунт. Сессия в терминале не прерывается.

```
┌──────────────────────────────────────────────────────────┐
│                   CLI Агент (в терминале)                │
│             Pi Coding Agent  /  Hermes Agent             │
└────────────────────────────┬─────────────────────────────┘
                             │  Запросы к http://127.0.0.1:4000/v1
                             ▼
┌──────────────────────────────────────────────────────────┐
│              OpenCode Unlimited Smart Proxy              │
│  - Обход 403 (генерация tU-сигнатур и User-Agent)        │
│  - Simple-shuffle балансировка нагрузки                  │
│  - Авто-кулдаун 60 сек при 429 (Rate Limit)              │
│  - Мгновенный прозрачный повтор через живые ключи        │
└───────┬───────────────────┬───────────────────┬──────────┘
        │                   │                   │
        ▼                   ▼                   ▼
┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│  OpenCode #1 │    │  OpenCode #2 │    │  OpenCode #3 │ ... (N аккаунтов)
└──────────────┘    └──────────────┘    └──────────────┘
```

## ⚡ Быстрый старт (для любого разработчика)

### 1. Клонируйте репозиторий
```bash
git clone https://github.com/sidzuya/unlimited-token.git
cd unlimited-token
```

### 2. Создайте файл `.env` и добавьте ключи
Скопируйте шаблон:
```bash
cp .env.example .env
```
Откройте `.env` и вставьте ваши API-ключи от аккаунтов OpenCode (минимум 1, рекомендуется 3+):
```env
OPENCODE_KEY_1=sk-ваш-первый-ключ-от-аккаунта-1
OPENCODE_KEY_2=sk-ваш-второй-ключ-от-аккаунта-2
OPENCODE_KEY_3=sk-ваш-третий-ключ-от-аккаунта-3
```

### 3. Установите Pi Coding Agent (если ещё не установлен)
```bash
npm install -g --ignore-scripts @earendil-works/pi-coding-agent
```

### 4. Запустите прокси
```bash
./start-proxy.sh
```
> Скрипт сам создаст виртуальное окружение Python, установит нужные зависимости и автоматически сконфигурирует Pi Coding Agent (`~/.pi/agent/models.json`).

### 5. Начните кодить в соседнем терминале!
```bash
./run-pi.sh
```
или напрямую:
```bash
pi --provider opencode-proxy --model big-pickle
```

## 🎯 Доступные модели

| Модель | Описание | Контекст | Назначение |
| :--- | :--- | :--- | :--- |
| **`big-pickle`** *(рекомендуется)* | Быстрая, точная модель для генерации кода и правок | 128K | Основной кодинг, рефакторинг, тесты |
| **`deepseek-v4-flash-free`** | Глубокие рассуждения и логика (DeepSeek) | 64K | Архитектура, алгоритмы, сложные баги |
| **`nemotron-3-super-free`** | Большой контекст от NVIDIA | 128K | Чтение документации, логов и спецификаций |

### Смена модели на лету:
Внутри интерактивной сессии Pi CLI напишите:
```text
/model
```
и выберите любую стрелочками!

## 🛡️ Советы по безопасной регистрации 3+ аккаунтов (Анти-бан)

Чтобы OpenCode не объединил аккаунты в одну группу:
1. **Смена IP (Раздача с телефона)**: Включите авиарежим на смартфоне на 5 секунд и выключите — мобильный оператор выдаст новый чистый IP.
2. **Разные профили браузера**: Используйте разные профили Chrome / Brave или Firefox Multi-Account Containers.
3. **Разные почты**: Зарегистрируйте аккаунты через разные Google / GitHub аккаунты на [opencode.ai/zen](https://opencode.ai/zen).

## 🧰 Использование с Hermes Agent

Если вы предпочитаете **Hermes Agent**:
1. Выполните скрипт автонастройки:
   ```bash
   ./configure-hermes.sh
   ```
2. Запустите агент:
   ```bash
   hermes
   ```

## 🛠️ Полезные команды

- `./start-proxy.sh` — запустить прокси на порту 4000.
- `./test-keys.py` — проверить статус и валидность всех ключей из `.env`.
- `./test-proxy.py` — тестовый запрос ко всем 3 моделям через прокси.
- `./run-pi.sh` — быстрый запуск Pi Coding Agent.
- `pi --list-models` — список зарегистрированных моделей.
